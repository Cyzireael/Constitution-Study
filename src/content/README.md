# 课程内容目录

本目录用于存放与程序代码分离的课程内容。`course.json` 收录第一讲 PPT 的结构化知识点；练习题与主观题目前仍为空。

## 内容约束

- 只依据用户提供的老师 PPT 和课堂笔记整理。
- 每个知识点必须有唯一 ID、名称、章节、讲解、来源文件、PPT 页码和核对状态。
- 来源核对状态为：待整理、待核对、已核对。
- 练习题、主观题必须关联知识点 ID。
- 主观题的参考答案与评分要点必须有资料依据；未覆盖时标注“资料未覆盖”。

字段定义见 `types.ts`。不要将课程正文硬编码在页面组件中。

第一讲文件在项目中的实际路径为 `source-materials/lecture-01.pptx.pptx`；知识点来源字段保留了此原始文件名。要求中写的是 `lecture-01.pptx`，但目录内实际文件名多了一个 `.pptx` 扩展名，原文件未重命名。

第一讲录入时核对了全部 61 页的幻灯片文本及 4 个 SmartArt 图示。第36、37页为课堂提问，未在知识库中替问题补充答案；第50页原文事件材料保留为待核对内容。
